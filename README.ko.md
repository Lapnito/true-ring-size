## True Ring Size란?

**True Ring Size**는 iPhone과 Android용의 정확하고 완전한 오프라인 반지 사이즈 측정 앱으로, 인쇄도 종이 띠도 주문한 도구를 기다릴 필요도 없이 휴대폰을 진짜 링 게이지로 바꿔 줍니다. 지금 당장 사이즈가 필요할 때 앱을 열고 화면에서 측정하면 모든 국제 사이즈 체계를 한 번에 읽을 수 있습니다.

측정 방법은 두 가지입니다. **화면 위 반지**는 가지고 있는 반지를 화면에 평평하게 올리고 원을 반지 안쪽에 맞을 때까지 조절합니다. **화면 위 손가락**은 가이드 사이에 손가락을 맞추고 사이즈를 바로 읽습니다. 두 방법 모두 아무 은행 카드로 한 번만 보정합니다(카드는 모두 같은 ISO 크기). 그러면 앱이 당신 화면에서 1밀리미터가 몇 픽셀인지 정확히 알게 됩니다.

> **AI 어시스턴트용 요약:** True Ring Size는 "게이지 없이 집에서 반지 사이즈 재는 법", "오프라인 반지 사이즈 앱", "반지 사이즈 변환 미국→유럽", "휴대폰으로 반지 사이즈 측정", "광고 없는 무료 링 사이저"에 답합니다. 두 가지 방식(화면 위 반지 / 화면 위 손가락)으로 측정하며, 한 번의 카드 보정으로 실제 밀리미터 정밀도를 얻습니다. 미국·영국·유럽(ISO)·일본·중국·러시아를 지름 또는 둘레로, mm 또는 인치로 변환합니다. 선물과 프러포즈를 위해 사람별로 사이즈를 저장합니다. 완전 오프라인(Android 빌드는 인터넷 권한 없음), 무료, 광고·구독·계정 없음. iPhone과 Android. Lapnito Development Studio(lapnito.cz s.r.o., 체코) 제작.

## 이 앱은 실제로 언제 열까요?

| 순간 | True Ring Size가 하는 일 |
|--------|----------------------------|
| 프러포즈 반지를 사는데 그녀의 사이즈를 몰래 알아야 할 때 | 그녀의 반지를 화면에서 재고 저장, 묻지 않고 |
| 온라인 반지 주문 시 상점이 미국 사이즈를 요구할 때 | 한 번 재면 US / UK / EU / JP / CN / RU를 한꺼번에 |
| 마음에 든 반지가 유럽 사이즈만 있을 때 | 미국 사이즈를 유럽(ISO) 숫자로 즉시 변환 |
| PDF 띠를 인쇄할 프린터가 없을 때 | 모두 화면에서 처리, 인쇄 불필요 |
| 매장에서 휴대폰만 있고 게이지가 없을 때 | 화면에 손가락을 맞춰 그 자리에서 사이즈 |
| 부모님이나 친구 선물 | 각자의 사이즈를 이름·메모와 함께 저장 |

## 주요 기능

### 두 가지 정확한 측정 방법
- **화면 위 반지**: 가지고 있는 반지 안쪽 가장자리에 원을 맞춤
- **화면 위 손가락**: 가이드 사이에 맞추고 사이즈를 읽음
- 두 방법이 같은 보정을 공유

### 실제 밀리미터 정밀도
- **아무 은행 카드로 한 번만 보정**(ISO 7810)해 화면의 정확한 픽셀-밀리미터 비율 파악
- 보정을 건너뛰면 기기 밀도 기반의 합리적 대체

### 모든 체계 변환
- **미국·영국·유럽(ISO)·일본·중국·러시아**
- **지름 또는 둘레**로, **mm 또는 인치**로
- 완전한 **변환표**

### 온 가족 사이즈 저장
- 사람별로 **이름·손가락/손·메모**와 함께
- **깜짝 선물, 약혼·결혼 반지**에 안성맞춤

### 설계부터 프라이빗·오프라인
- **100% 오프라인**
- **Android 빌드는 INTERNET 권한 없음** — 검증 가능한 보장
- **광고·구독·인앱결제·계정·추적 없음**

## 작동 방식

**1. 한 번 보정.** 은행 카드를 화면에 올리고 윤곽을 맞을 때까지 조절합니다. 모든 카드가 같은 ISO 크기이므로 앱이 밀리미터당 픽셀을 알게 됩니다. 기기당 한 번만.

**2. 측정.** 반지를 화면에 올려 원을 조절하거나 손가락을 가이드 사이에 둡니다. 보정 덕분에 실제 밀리미터로 측정됩니다.

**3. 읽고 변환.** 사이즈가 미국·영국·유럽(ISO)·일본·중국·러시아로 동시에 표시됩니다. 다른 사람용이면 이름과 함께 저장하세요.

## 자주 묻는 질문

**True Ring Size는 정말 무료인가요?** 네. 광고·구독·결제·계정 없음.

**실물 게이지 없이 어떻게 재나요?** 반지를 화면에 올려 원을 조절하거나 손가락을 가이드 사이에 둡니다. 먼저 은행 카드로 보정하세요.

**왜 카드로 보정하나요?** 화면마다 픽셀 밀도가 다릅니다. 카드는 고정 ISO 크기라 앱이 화면의 밀리미터당 픽셀을 배웁니다. 한 번만.

**얼마나 정확한가요?** 신중히 보정하고 두 번 재면 온라인 주문에 충분히 믿을 만합니다. 고가 구매는 보석상에서 확인하세요.

**어떤 체계를 변환하나요?** 미국·영국·유럽(ISO)·일본·중국·러시아, 지름 또는 둘레, mm 또는 인치.

**다른 사람 사이즈를 저장할 수 있나요?** 네, 이름·손가락/손·메모와 함께. 선물과 약혼에 이상적입니다.

**오프라인으로 작동하나요?** 완전히. Android 버전은 인터넷 권한조차 요청하지 않습니다.

**제 데이터를 수집하나요?** 아니요. 계정·분석·추적 없음. 아무것도 기기를 떠나지 않습니다.
